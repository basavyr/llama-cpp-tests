# `llama.cpp` Tests

This repository contains several C++ implementations for testing the capabilities of [`llama.cpp`](https://github.com/ggml-org/llama.cpp).

## Releases

At the time of testing (November 2025), we used the `master` branch for building the project from source (according to [this guide](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md)).
